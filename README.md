UniApp 商城项目
项目简介
本项目是一个基于UniApp框架开发的移动端商城应用。UniApp 是一个使用 Vue.js 开发所有前端应用的框架，开发者编写一套代码，
可发布到 iOS、Android、H5、以及各种小程序（微信、支付宝、百度、头条、QQ、钉钉、淘宝）、快应用等多个平台。

功能模块
1. 用户模块
用户注册与登录: 支持微信注册与登录。
个人信息管理: 用户可以查看和编辑个人信息，包括头像、昵称等

2. 商品模块
商品展示: 首页展示热门商品、新品推荐等。

商品分类: 按类别浏览商品，支持多级分类。

商品搜索: 支持关键词搜索商品。

商品详情: 查看商品详细信息，包括图片、描述、价格等。

3. 购物车模块
添加商品: 用户可以将商品添加到购物车。

购物车管理: 用户可以查看购物车中的商品，修改数量，删除商品。

结算: 用户可以选择购物车中的商品进行结算。

4. 订单模块
下单: 用户可以选择收货地址、支付方式等进行下单。
